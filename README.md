# KnowBall 🏆

The daily 4×4 all-sports trivia matrix connecting the **NFL, NBA, MLB, and NHL** with cross-sport statistical homonyms, team franchises, accolades, and metro markets.

## Features
- **4×4 Matrix (16 Cells):** Match athletes who satisfy both intersecting row and column criteria.
- **Cross-Sport Statistical Homonyms:** Exploit shared terms like *Steals*, *Assists*, *Hits*, *Points*, *Saves*, and *Turnovers* across different professional leagues.
- **Grand Slam Diversity Bonus:** Use athletes across all 4 major sports to unlock a 25% rarity score discount.
- **Game Modes:** Casual (4 strikes) and Immaculate (16 guesses, 0 errors).
- **Stadium Cyber-Neon UI:** Responsive mobile-first grid, Varsity sport radar quadrant dial, and single-row command header.
